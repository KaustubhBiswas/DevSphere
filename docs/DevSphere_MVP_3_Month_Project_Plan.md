# DevSphere MVP Roadmap (3-Month Plan)

## Vision

Build a production-quality Developer Collaboration Platform using Spring
Boot.

## Tech Stack

-   Java 21
-   Spring Boot 3.x
-   Maven
-   PostgreSQL
-   Spring Security
-   Redis
-   Kafka
-   Docker
-   GitHub Actions

## Scope (MVP)

### Included

-   Authentication (JWT, Refresh Tokens)
-   User Profiles
-   Organizations & Roles
-   Projects
-   Tasks
-   Issues
-   Comments
-   Dashboard
-   Notifications
-   WebSocket Chat
-   Redis Caching
-   Kafka Events
-   Docker Deployment

### Excluded (Future)

-   Microservices
-   Kubernetes
-   Spring Cloud
-   Elasticsearch
-   AI
